# Icons from files

Put official icon sets here, one folder per vendor, and refer to them from a spec with
`"icon": "file:<folder>/<name>.svg"`:

- `k8s/`: the Kubernetes icons from the kubernetes/community repository (`icons/svg`).
- `aws/`: the AWS Architecture Icons, from the AWS architecture icons page.

Check each set's license before you publish a diagram that uses it. A spec can also keep its
own icons next to the spec file; that folder is searched first.
