# Feature Builder

Automated end-to-end feature development using Ralph Loop for iterative implementation and AI code review for quality assurance. Use when building, implementing, creating, or developing any feature, component, endpoint, module, or functionality.

## Installation

```bash
# From this repository
claude skill add ./skills/feature-builder

# Manual installation
cp -r skills/feature-builder ~/.claude/skills/
```
